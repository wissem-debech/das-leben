# Das Leben A1 – Review app

Interactive review app for the German A1 textbook *Das Leben*, organised by the book's units (Start + Einheit 1–16).

- **Grammatik** – 42 rules with examples, common mistakes, quizzes, Plateau tests and a final test
- **Verben** – 85 key verbs with Präsens, Perfekt, Imperativ (and Präteritum for sein, haben and modal verbs), irregular forms highlighted
- **Wortschatz** – 227 nouns with der / die / das, plural and meaning; article trainer, word choice and flashcards

Interface in Arabic, English and French. Progress is saved in the browser.
