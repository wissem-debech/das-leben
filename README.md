# Das Leben A1 – Review app

Interactive review app for the German A1 textbook *Das Leben*, organised by the book's units (Start + Einheit 1–16).

- **Grammatik** – 49 rules with examples, common mistakes, quizzes, Plateau tests and a final test
- **Verben** – 147 verbs from the book's word list with Präsens, Perfekt, Imperativ (and Präteritum for sein, haben and modal verbs), irregular forms highlighted
- **Wortschatz** – 435 nouns from the book's word list (A1 exam vocabulary) with der / die / das, plural and meaning; article trainer, word choice and flashcards

Interface in Arabic, English and French. Progress is saved in the browser.
